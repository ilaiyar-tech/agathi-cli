# Support Guide

If you're having trouble with tu2pu, please review the options below to find the best way to get help.

---

## 1. Documentation

Before opening an issue or asking for support, please review our documentation:
- **[README.md](README.md):** Getting started, features, requirements, and examples.
- **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md):** How the system is designed.
- **[docs/PLATFORM_IDENTITY.md](docs/PLATFORM_IDENTITY.md):** Naming and specifications.

---

## 2. Diagnostics Tool

If you're experiencing connectivity or workspace errors, run the built-in system doctor:
```bash
tu2pu doctor
```
This utility will check the status of the local background server, DB file locks, workspace configuration registry, and key modules.

---

## 3. GitHub Issues

If you've verified that the issue is a bug or you have a feature request:
- Search the [GitHub Issues](https://github.com/ilaiyar/tu2pu/issues) list to check if it's already reported.
- If it's a new issue, use our bug template or feature template to open a ticket.

---

## 4. Contact

For business inquiries, professional deployment assistance, or enterprise support, please reach out to **support@tu2pu.in** or visit [tu2pu.in](https://tu2pu.in).
