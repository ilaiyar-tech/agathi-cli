# Changelog

All notable changes to the **tu2pu** project will be documented in this file.

---

## [1.0.0] - 2026-07-18

This is the official public release of **tu2pu v1.0.0**, the production-ready AI-powered development CLI platform (formerly known as Context OS & Cognitive Execution Layer).

### Rebranding & Identity Migration
- Officially rebranded the user-facing product name to **tu2pu**.
- Re-linked all remote endpoints to route securely to `https://api.tu2pu.in`.
- Provided the legacy compatibility command `agathi` with a forwarding layer and deprecation notice.
- Rebranded the console headers, sidebar panel, terminal shell welcome flags, and system agent prompt profiles.

### CLI & Interactive REPL
- Implemented a complete CLI interface using `Commander.js` and colored chalk terminal aesthetics.
- Added interactive REPL shell with autocomplete, session management, slash commands, and persistent command history.
- Provided built-in diagnostic diagnostics command: `tu2pu doctor`.

### Cognitive Execution Layer (CEL)
- Standardized execution planning and sequential pipeline runs.
- Added parallel command running, validation heuristics, and self-correcting trust protocols.
- Integrated automatic workspace scans and index tracking.
- Set up accuracy verification and telemetry logs.
