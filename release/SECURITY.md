# Security Policy

## Supported Versions

The following versions of tu2pu receive security updates:

| Version | Supported |
| :--- | :--- |
| **v1.x** | ✅ Yes |
| **< v1.0.0** | ❌ No (Deprecated Alpha/Beta releases) |

---

## Reporting a Vulnerability

We take the security of tu2pu seriously. If you find a vulnerability or security flaw in the system, please do **NOT** open a public issue. Instead, report it privately.

Please report vulnerabilities by emailing **security@tu2pu.in**.

### What to Include:
* A detailed description of the vulnerability.
* Steps to reproduce the issue (PoC scripts or command sequences are highly appreciated).
* Potential impact and how it can be exploited.

### Response Process:
1. We will acknowledge receipt of your vulnerability report within 24 hours.
2. We will investigate the issue and coordinate a fix.
3. We will release a security patch and credit you for the discovery (unless you request anonymity).
